| Time | Screen action | Presenter cue |
|---|---|---|
| Before recording | Start API + React demo, then Streamlit ops console. Reset Streamlit to replacement-blocked state. | Confirm the live provider badge says Gemini. Never describe `offline-demo` as live reasoning. |
| 0:00 | React live trace at 1920×1080. | “Resolve outcomes, not just conversations.” |
| 0:25 | Choose Adaptive resolution and start CASE-100. | Point to entity resolution, provider name, and streaming trace. |
| 0:55 | Highlight Policy Evidence, then inventory. | Emphasize “policy RAG informs; deterministic rules authorize” and “zero units.” |
| 1:30 | Point to ADAPT PLAN. | Say “the tool result caused replanning,” not “fallback script.” |
| 2:10 | Show CREATE REFUND then VERIFY; briefly open Streamlit Audit. | Accent: “transactional mutation,” “idempotent,” “closed-loop verification.” |
| 2:40 | Show provider badge, audit, and resolved state. | Close with the complete agentic loop and explicit fallback visibility. |

Use deliberate cursor movement and a pointer halo. Avoid scrolling while a key state transition is on screen. Keep the Demo & Simulation view offscreen unless showing a controlled resilience test.

Submission naming: use `[TeamName]_Github/Agentic` for the repository package and `[TeamName]_video_agentic` for the video file.
